# Sigil has moved — and is now **Sigyll**

The PKI management tool formerly developed here under `examples/CA/` has been
renamed to **Sigyll** and extracted into its own repository:

## 👉 https://github.com/JoeShook/Sigyll

consume the udap-dotnet SDK as NuGet packages. The full git history was
preserved during the extraction.
